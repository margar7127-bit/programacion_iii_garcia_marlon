## Descripción

Repositorio correspondiente a la materia **Programación III**, donde se desarrollarán diferentes prácticas, ejercicios y proyectos relacionados con el desarrollo web moderno.

Durante el curso se trabajarán tecnologías fundamentales para la creación de aplicaciones web, comenzando con los conceptos básicos de frontend y avanzando hacia el desarrollo de aplicaciones utilizando frameworks y herramientas modernas.

---

## Tecnologías y conceptos

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de una página web.

Se trabajarán conceptos como:

* Estructura básica de una página web.
* Etiquetas HTML.
* Formularios.
* Enlaces e imágenes.
* Tablas.
* Elementos semánticos.

---

### CSS

**CSS (Cascading Style Sheets)** permite definir la apariencia y presentación de las páginas web.

Se estudiarán conceptos como:

* Selectores.
* Colores y tipografías.
* Márgenes y espacios.
* Flexbox.
* Grid.
* Diseño responsive.
* Animaciones y transiciones.

---

### JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar comportamiento e interactividad a las páginas web.

Se trabajarán temas como:

* Variables y constantes.
* Tipos de datos.
* Condicionales.
* Ciclos.
* Funciones.
* Arrays y objetos.
* Manipulación del DOM.
* Eventos.
* Consumo de APIs.

---

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que facilitan el desarrollo de aplicaciones grandes.

Se estudiarán conceptos como:

* Tipos de datos.
* Interfaces.
* Clases.
* Herencia.
* Tipado de funciones.
* Genéricos.
* Módulos.
* Programación orientada a objetos.

---

### NestJS

**NestJS** es un framework para desarrollar aplicaciones backend utilizando Node.js y TypeScript.

Se trabajarán conceptos relacionados con:

* Creación de APIs REST.
* Controladores.
* Servicios.
* Módulos.
* Inyección de dependencias.
* DTOs.
* Validaciones.
* Manejo de peticiones HTTP.

---

### ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para construir interfaces de usuario mediante componentes reutilizables.

Se estudiarán conceptos como:

* Componentes.
* JSX.
* Props.
* Estado.
* Hooks.
* Eventos.
* Formularios.
* Consumo de APIs.
* Renderizado dinámico.
